# ksp11 — minimal PKCS#11 software token

A minimal PKCS#11 v2.40 module (`.so`) that exposes a **single private key**
(RSA or EC) as a token object, used to test keyless TLS proxy signing with
OpenSSL's `pkcs11-provider`.

The token loads its key from a PEM file at `C_Initialize` time. Key path comes
from the `KSP11_KEY_PATH` environment variable (default `./test-key.pem`).

## Build

```bash
make            # produces ksp11.so
```

Dependencies: `gcc`, `libssl-dev`, `libp11-kit-dev` (for `pkcs11.h`),
`openssl` 3.x with the `pkcs11-provider` package.

## Test with OpenSSL

```bash
make test       # runs test-sign.sh
```

`test-sign.sh` generates RSA + EC test keys, wires `pkcs11-provider` to
`ksp11.so` via an OpenSSL config, and verifies:

1. the provider loads the private key through the token URI
   `pkcs11:token=ksp11-token;object=test-key;type=private`
2. RSA PKCS#1 v1.5 signing (`openssl dgst -sign`) + verify
3. RSA-PSS signing + verify
4. raw PKCS#1 via `openssl pkeyutl -sign` + verify
5. ECDSA signing + verify

Manual run:

```bash
export OPENSSL_CONF=$PWD/ksp11.cnf      # generated by test-sign.sh
export KSP11_KEY_PATH=$PWD/test-key.pem
URI='pkcs11:token=ksp11-token;object=test-key;type=private'
openssl dgst -sha256 -provider pkcs11 -provider default -sign "$URI" -out sig.bin msg.txt
openssl dgst -sha256 -verify test-pub.pem -signature sig.bin msg.txt
```

## What is implemented

- slot/token/session management (one slot, read-only sessions, no PIN;
  `C_Login` always succeeds)
- object enumeration: one private + one public key object
  (`CKA_ID=0x01`, `CKA_LABEL=test-key`)
- attribute retrieval: `CKA_MODULUS`/`CKA_PUBLIC_EXPONENT` (RSA),
  `CKA_EC_PARAMS`/`CKA_EC_POINT` (EC); private components are returned as
  `CKR_ATTRIBUTE_SENSITIVE`
- signing, single- and multi-part: `CKM_RSA_PKCS`, `CKM_RSA_PKCS_PSS`,
  `CKM_SHA{256,384,512}_RSA_PKCS[_PSS]`, `CKM_ECDSA`,
  `CKM_ECDSA_SHA{256,384,512}`
- `C_GenerateRandom`

Everything else returns `CKR_FUNCTION_NOT_SUPPORTED`.

## Quirks to know

- **ECDSA returns raw `r||s`**, not DER. `pkcs11-provider` converts the
  token's output with `convert_ecdsa_raw_to_der` (see
  `latchset/pkcs11-provider` `src/sig/ecdsa.c`), so the module hands back
  `r||s` padded to the field size (64 bytes for P-256).
- The token has no PIN; set `pkcs11-module-token-pin` in the provider config
  to suppress the interactive prompt.
- `KSP11_DEBUG=1` enables call tracing on stderr.
