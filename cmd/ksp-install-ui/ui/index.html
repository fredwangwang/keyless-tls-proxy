About Keyless TLS Proxy KSP

This utility installs remote certificates into the Windows Certificate Store (MY) and binds their private key operations to the Fred Proxy Key Storage Provider (KSP) via CNG.

How it works: When a Windows application (IIS, Chrome, Edge, Schannel) requests a private key operation (signing / TLS handshake), CNG invokes fredprx_ksp.dll, which proxies the cryptographic operation over mTLS gRPC to the remote TPM/HSM server without exposing the raw private key.
